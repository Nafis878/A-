Bounded-memory transformers · recurrent K/V injection

The write rule needs a latch

Maglev rebuilds its memory state from scratch at every step. To remember anything, the model must first discover a saturated attractor — and usually doesn’t. Adding a one-line identity path removes that requirement and the failure disappears. In synthetic retrieval this is decisive. In language modelling it is absent, and that null is reported here as prominently as the positive result.

What is being tested

Maglev’s decoder carries a memory vector between steps and writes it as m_t = decoder_norm(h_t) — a fresh function of the current hidden state, with no path from m_{t−1} to m_t except through the network. Retaining a fact therefore requires learning the identity function through a normalisation layer.

The probe is delayed recall: a key–value pair is planted, filler follows, then the key is queried. With window W and L layers the decoder’s stacked local reach is L·(W−1), so every probe distance is placed beyond it and no instance is answerable without memory. Training runs through the recurrence (BPTT), so the path being evaluated is the path being optimised.

The intervention is one line — m_t = f·m_{t−1} + (1−f)·decoder_norm(h_t) with a learned gate. It is a standard forget gate, and the contribution here is the diagnosis, not the cure.

Mechanism: latch versus maintenance

Holds

A contradiction in our own output forced this. One write-rule cell solves distance 24 at accuracy 1.000 while recording a one-step gain of ρ = 0.093. Compounded over 24 steps that is 10−20. Three explanations were tested; the first two are wrong and are kept because the third is only credible against them.

 Task signal is the separation between two memory trajectories differing only in the planted value, relative to memory scale. For the identity path, ρ24 predicts the closed-loop sensitivity within 27% — that channel really is linear. For the write rule it is wrong by 13 to 41 orders of magnitude.

The successful write-rule cell carries the answer perfectly — the two trajectories separate at the needle and are still 1.43 apart at the query, worth a 13.7 logit margin — while its Jacobian reads 2×10−7. It has learned a latch: a saturated attractor, invisible to any linearisation, because perturbations decay back into the basin they came from. The identity path instead has a linear maintenance channel, ρ ≈ 1 at every position.

That is the mechanism behind the scale trend. A latch is a brittle thing for gradient descent to find, and evidently harder to stumble into as width grows — not easier.

Consequence for anyone reading ρ elsewhere in this work: it measures whether a channel is linear and maintained. It must never be compounded over distance, and a severed write should be confirmed against the task signal, not ρ alone.

Language modelling

Null — effect absent

Character-level text8, same geometry as the ladder’s base rung. Aggregate bits-per-byte shows no defect: the write rule’s channel is alive (ρ = 0.27–0.43, against ~0.002 in a failed synthetic cell), memory buys it 1.52 bits, and it is the better language model.

Aggregate BPB cannot test the hypothesis, though, and that is measurable rather than arguable: only 0.57% of held-out positions are ones where the next character is fixed by a substring absent from training that last occurred a median of 72 characters back. So those positions were measured directly, with the prediction written down first — the write rule should lose there, and lose by more with distance.

The prediction is refuted. The write-rule failure does not appear in character-level language modelling, not even at the positions constructed to expose it, and the intervention costs LM quality. A coherent reading is that text never demands what the synthetic probe demands — exact recall of an arbitrary, non-redundant token — so a partially decaying channel suffices. That reading is consistent with the data but is not itself tested here.

Errors found and corrected

Each of these changed a number that would otherwise have been published. They are listed because a reviewer should be able to see what the validity checks caught.

  • Fisher test returned exactly zero. The hypergeometric tail summed from the wrong lower bound, giving an empty range whenever one arm is perfect — precisely the 10/10 vs 3/10 table the headline rests on. Now checked against SciPy on seven tables.
  • Arms assembled by run name dropped three seeds. The ten seeds per arm came from three scripts under unrelated names; name matching reported 2/7 vs 8/8 instead of 3/10 vs 10/10. Arms are now selected by config.
  • A binary success criterion hid a 6.4× gap. Built for the bimodal 2-value task, it counted a 0.143 cell as “learned” beside a 0.906 one and reported the 16-value result as p = 0.50.
  • The first LM metric was confounded. Bits bought by memory rewards a worse local baseline, so the identity path’s apparent advantage came from its ablated model being worse, not its deployed model being better.
  • Two-hop leaked the answer into the local window in 60.9% of instances.

Limitations

  • No language-model claim is supported. The effect is absent under a measurement built to detect it, and the intervention degrades LM quality on every seed.
  • Depth is not scaled. Every rung is two layers — which is what keeps the task comparable, since reach is L·(W−1) — so the ladder isolates parameter count and leaves depth untested.
  • Maglev’s published result is not reproduced. The defect is shown in a reimplementation of its write rule, not in its reported setting.
  • The intervention is a standard forget gate. The contribution is the diagnosis — that the write rule forces the model to discover a latch — not the fix.
  • One task family, one probe design. Delayed recall and needle share a planting routine; two-hop was excluded as invalid.

Reproducing this

Every number above is recomputed from archived JSON that embeds its own full configuration. No checkpoint, scratch directory or GPU is required. 

python evidence/verify.py        # recompute every headline from the archive
pytest tests/ -q                 # 179 tests, including regression locks on the
                                 # headline, the stratified statistic and the
                                 # bit-exact resume path

129 result files are tracked in the repository. Checkpoints are deliberately not archived — roughly 51 MB per cell against 2.5 KB of JSON, and nothing here needs them.

All statistics are exact conditional or exact permutation tests; no normal approximations are used. Where a test’s smallest attainable p-value is bounded by the number of seeds, that floor is reported alongside it.
